Ce dossier contient des ressources à destination des personnes qui vont dérouler le module/projet (ie. les pédagos).

Elles doivent être uploadées dans les instances de modules (sur intranet ou moodle ou autre) MAIS elles ne doivent PAS être accessibles par les apprenants.

Par exemples, c'est ici qu'on pourrait mettre :

- les templates PPTX pour les kick-off (ou tout autre document de présentation) ;

- les consignes de suivi et/ou d'évaluation à destination des pédagos ;

- un bout de code pour lancer un docker, des tests, une commande sur les repos, un scrap sur l'intranet, etc ;

- des fichiers de tests et/ou de référence pour le module/projet, si ceux-ci ne possèdent pas déjà leur propre repo (dans quel cas, indiquer ici le lien vers ce repo semble idéal).
